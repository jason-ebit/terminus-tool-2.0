### Quick Start Guide Summary for Developers

#### Main Purpose
This guide provides a quick and practical way to get started with Terminus 3, enabling developers to create and submit tasks efficiently.

#### Key Setup Steps or Requirements
1. **Prerequisites:**
   - Access to the Snorkel Expert Platform.
   - Joined the Slack channels `#terminus-3-submissions` and `#terminus-3-announcements`.
   - Installed and configured the Snorkel CLI, including login, key refresh, and task submission via CLI (optional).

2. **Environment Setup:**
   - **Option A: Quick Setup with uv (Recommended)**
      - Install uv (Python package manager)
      - Install the Snorkel CLI
      - Log in and configure credentials
   - **Option B: Manual Setup**
      - Install Docker Desktop (version 24.0.0 or higher)
      - Verify Docker installation
      - Install the Snorkel CLI
      - Configure API keys
   - **Note:** Docker Desktop requires version 24.0.0 or higher. On macOS, enable "Allow the default Docker socket to be used" in Docker Desktop settings.
   - **Additional Tools:**
      - Install VS Code extensions: Docker, Python, Markdown, TOML, and GitLens.

#### Important Warnings or Gotchas
- Ensure Docker Desktop is running and properly configured.
- Check permissions for Docker socket on macOS.
- Verify credentials for the Snorkel CLI and AI credentials.
- Ensure Docker and Snorkel CLI versions are compatible with Terminus 3.
- Use the complete [Platform Submission Guide](/portal/docs/submitting-tasks/platform-submission) for detailed task setup instructions.

#### Recommended Next Actions
- Read [What Makes a Good Task](/portal/docs/understanding-tasks/what-makes-a-good-task) to understand quality guidelines.
- Review [Task Components](/portal/docs/understanding-tasks/task-components) for task structure details.
- Use the [Submission Checklist](/portal/docs/submitting-tasks/submission-checklist) to ensure tasks are ready for submission.

---

This summary should help developers quickly set up and get started with Terminus 3, covering the main points and essential setup steps.
